# JKL Tech - IT Company Website

Our website was developed for an imaginary IT company called JKL Tech to advertise job positions, allow users to apply, and manage submitted application records. The website includes a home page, a page for our group details, a page outlining the job positions, a page to apply, and a page detailing the enhancement features implemented in the website. A manager can also log in to access the management page displaying all EOI records.

---

Features include:
- Job posting & application form with client-side validation
- Secure data handling with prepared SQL statements and input sanitization
- Session-based login, hashed passwords, and 3-attempt lockout policy
- Role-based access to manager dashboard
- Search and sort options to list EOIs
- CRUD operations to update and delete EOIs
- Responsive and accessible web design with CSS animations

---

## Running the Application
1. Download files
2. Open terminal and run
```
bash
php -S localhost:8000
```
3. Open your browser and navigate to http://localhost:8000 to use the web application.
